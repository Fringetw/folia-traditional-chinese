# 更新到 1.1.1

這次只補必要修正：字幕版本比對與搜尋失敗原因，沒有再擴充大型功能。

| 檔案 | 用途 |
| --- | --- |
| `opencc-traditional-lyrics-1.1.1.zip` | 安裝至 Folia，以及作為 GitHub Release 附件。 |
| `folia-traditional-chinese-1.1.1-update.zip` | 解壓後將內層 `folia-traditional-chinese/` 的內容更新至 GitHub 根目錄。 |

## GitHub

1. 上傳更新包中的原始碼內容，避免多包一層資料夾。
2. 確認 `.github/workflows/ci.yml` 和 `.gitignore` 也有上傳；GitHub 網頁上傳容易漏掉這兩個隱藏項目，本包已包含。
3. 等待 Actions 的兩個 Folia 版本檢查與測試通過。
4. 以通過檢查的 commit 建立標籤 `v1.1.1`，Release 標題填 `OpenCC 繁體字幕 v1.1.1`。
5. 發布說明使用 `docs/releases/v1.1.1.md`，附上對應安裝 ZIP。既有 1.1.0 Release 可以保留。

## 模組市場

模組 ID 保持 `opencc-traditional-lyrics`，版本欄填 `v1.1.1`，發布渠道保持不變。

更新說明可使用：

> 1.1.1 修正歌名括號資訊被刪除而可能誤配不同分部／版本的問題，整份備援改為要求精確歌名與歌手匹配，並增加日文版本標記辨識。搜尋狀態補上逾時、登入、來源限制、請求上限、無匹配與無字幕等原因；重試時清除舊原因。Folia v0.7.22、v0.7.23 各通過 128 項自動測試；來源回覆使用測試資料，未完成各平台真人帳號與完整 GUI 播放驗證。模組 ID、原始碼倉庫、模組目錄、權限、OpenCC 引擎及字典均未變更。請協助重新審查、簽章。

新版安裝包未簽章，不要複製其他版本的簽章。

## 實際播放確認

安裝後播放缺少中文的歌曲，使用「查看字幕來源與中文覆蓋率」確認結果與原因；再試快速切歌、還原原字幕及停用模組。尚未經你的實際使用環境驗證的部分，以試用結果為準。
