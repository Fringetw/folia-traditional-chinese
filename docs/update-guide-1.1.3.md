# 安裝與更新 1.1.3

## 使用者安裝

將 **opencc-traditional-lyrics-1.1.3.zip** 拖入 Folia「設定 → 模組」覆蓋安裝，啟用同一個 OpenCC 繁體字幕，再重新啟動 Folia 以清除舊模組與動畫快取。不必解壓縮；原始碼更新包不能當安裝包拖入。

先維持原本設定：「自動尋找中文字幕」及「字幕載入失敗時自動改用其他來源」開啟。Folia 的自動使用最佳歌詞與網易雲優先可先保留，不需要清空資料庫或重新登入。

如果中文仍未出現，在命令面板執行「查看字幕來源與中文覆蓋率」，開頭應為 **OpenCC v1.1.3**。需要時執行一次「重新尋找中文字幕」。

- 覆蓋率大於 0、卻沒有中文：檢查歌詞樣式視窗「字幕」是否包含「翻譯」。這與全域歌詞來源設定不同。
- 身分證據不足／無法對齊：插件保留原詞。原字幕完全沒有且無法確認藝名時，可在 Folia 原有匹配視窗選對版本並按「儲存」。
- 逾時、登入、來源限制或請求上限：屬於來源存取結果，插件會停止或改試候選，避免無限重試。
- 仍有問題時，提供上述版本／來源訊息與 Folia 開發者日誌的相關 `[OpenCC]` 行，不需要提供憑證或全部帳號日誌。

逐字資料缺失時只恢復逐行時間的基本動畫，無法重建來源沒提供的精確逐字時間。所有來源都沒有詞、行時間也無效時，不能憑空產生字幕。

## GitHub 更新

**folia-traditional-chinese-1.1.3-update.zip** 為原始碼。解壓縮後把 folia-traditional-chinese/ 內的內容上傳到儲存庫根目錄，保留 `.github/workflows/ci.yml` 與 `.gitignore`。此次沒有修改 GitHub 主分支或 Release。

待 GitHub Actions 成功後，以同一 commit 建立 v1.1.3 tag 與 Release，附件用專用安裝 ZIP。發布說明見 `docs/releases/v1.1.3.md`。

送審時 Mod id 保持 **opencc-traditional-lyrics**，Version 改為 **v1.1.3** 或相符 commit，Channel 保持原渠道，License 為 MIT（內附資料保留 Apache-2.0）。若沿用更新 issue，標題、版本、功能與測試數都要同步，避免仍寫 1.0.1 維護更新。

此修正版未簽章，必須重新送審；不能複製其他版本的簽章。可說明：修正跨平台名稱與翻唱漏配、保留原逐字資料補中文、缺失逐字資料退回逐行顯示；兩個 Folia 版本各通過 168 項測試，Chromium 渲染 26 項通過。來源回覆為合成資料，未完成私人帳號與 Windows 真實歌曲實播。沒有新增權限，原有簡轉繁引擎及顯示用字典不變。
