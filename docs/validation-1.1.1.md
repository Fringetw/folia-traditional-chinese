# 1.1.1 驗證紀錄

基於使用者 GitHub 的 1.1.0 原始碼 `acba206cd060a071ae30a98444715d0dc24649a1` 製作；模組 ID 保持 `opencc-traditional-lyrics`。

## 已確認的問題與修正

1. 1.1.0 會刪除歌名內所有括號內容，`Song (Part 1)` 與 `Song (Part 2)` 在相同歌手／時長下的匹配分數為 1。1.1.1 保留有意義的括號資訊，只忽略明確呈現標籤。
2. 很長的模糊歌名可能取得高於 0.98 的分數，被用作整份備援。1.1.1 將非精確匹配上限設為 0.97，只有正規化後的精確歌名和歌手才能取得 1。
3. 搜尋故障原本只顯示失敗數量。1.1.1 區分請求逾時、整輪截止、登入、地區／會員限制、請求上限、未設定來源、無匹配歌曲與無字幕，且重試時不沿用舊原因。
