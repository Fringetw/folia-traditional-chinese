## 先在 Folia 確認

1. 覆蓋安裝後，確認模組面板版本為 **1.1.2**，並已啟用。
2. 開啟模組設定的「自動尋找中文字幕」。
3. 播放原本只出現日文的歌曲，執行「重新尋找中文字幕」。
4. 執行「查看字幕來源與中文覆蓋率」。此處可確認實際字幕來源、中文覆蓋率、是否替換整份，以及時間對齊／故障原因。

音樂可以繼續用 YouTube Music，不需要改音樂播放來源。模組只改顯示資料，Folia 原本的來源標籤未必會改成網易雲。

若狀態有中文覆蓋率，但畫面沒中文，檢查歌詞樣式視窗的「字幕」頁，確認顯示內容包含翻譯。若顯示找不到匹配、無字幕、登入或連線錯誤，請保留這段狀態文字，才可區分比對、來源可用性與顯示設定問題。

在宿主「匹配歌詞」視窗只點候選會預覽；要手動套用，必須按右下角「儲存」。

## GitHub 與市場

將原始碼更新包內容上傳到根目錄，保留 `.github/workflows/ci.yml` 與 `.gitignore`，等待 Actions 通過後，以相同 commit 建立 `v1.1.2` 標籤與 Release。發布說明見 `docs/releases/v1.1.2.md`。

市場模組 ID 保持 `opencc-traditional-lyrics`，版本填 `v1.1.2`，發布渠道保持不變，更新說明可用：

> 1.1.2 修正雙語歌名及假名／羅馬字藝名跨來源比對失敗的問題，加入原文歌名與只查歌名的查詢退路。原字幕可用時優先補中文，支援相鄰分行合併與經多段原文核對的固定時間差對齊；無法完整補字時，只有原文與時間軸證據足夠才採用中文更完整的整份字幕。排除間奏佔位行，並顯示來源、整份替換與時間對齊資訊。音樂播放來源、模組 ID、權限、OpenCC 引擎與字典不變。Folia v0.7.22、v0.7.23 各通過 151 項自動測試，使用截圖中的名稱及合成字幕情境，並驗證真正宿主 LRC 解析器、公開 Omni 及安裝流程；沒有使用真人帳號或完整 GUI 實播驗證。請協助重新審查、簽章。

新 ZIP 未包含官方簽章，不要複製其他版本的簽章。這次新增兩項鎖定版本的開發測試依賴，沒有新增插件執行依賴。
