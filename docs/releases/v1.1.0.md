1.1.0 新增自動尋找中文字幕與字幕載入失敗備援，保留原有的離線 OpenCC 簡轉繁功能。

## 新功能

- 從 Folia 已設定、支援歌詞的來源搜尋同一首歌，核對歌名、歌手、版本與已知時長。
- 依中文譯文覆蓋率、格式與時間軸檢查選擇結果，跳過亂碼、佔位文字與明顯異常的重複譯文。
- 原字幕可用時，從原文相同且時間接近的候選補齊缺漏中文，保留原本的逐字時間軸、注音與和聲。
- 原字幕無法載入時，嘗試其他匹配版本；搜尋／載入失敗、逾時或無效就跳到下一個候選，全部失敗後停止。
- 新增標準／深入搜尋、重新尋找、還原原字幕及查看來源與覆蓋率。
- 加入切歌取消、帳號切換清理、記憶體暫存與請求上限，防止舊結果套到新歌或反覆請求。

模組 ID、OpenCC 引擎與字典維持不變，未新增模組權限。

## 安裝

下載附件 `opencc-traditional-lyrics-1.1.0.zip`，拖入 Folia「設定 → 模組」覆蓋安裝，再啟用模組。GitHub 自動產生的 Source code 壓縮包供開發使用。

此 GitHub 安裝包未包含官方簽章；市場版本需經重新審查與簽章，請以 [模組市場](https://folium-compound.cielaniska.top/#mod-opencc-traditional-lyrics) 的版本為準。

自動搜尋需網路，透過 Folia 已設定的來源查詢歌名與歌手，沿用 Folia 的登入狀態；插件不讀取帳號憑證，也沒有自己的伺服器。關閉「自動尋找中文字幕」與「字幕載入失敗時自動改用其他來源」後，仍可離線簡轉繁。

## 驗證與限制

已對 Folia v0.7.22、v0.7.23 各通過 111 項自動測試，包含宿主 DTO、重建流程、公開 Omni 服務與實際安裝包的安裝／覆蓋安裝。平台回覆與故障使用測試資料，未使用私人帳號實測各平台，尚未完成完整 Electron GUI 播放驗證。

品質評分衡量中文覆蓋率、格式與時間軸，**不等於 AI 語意審核**，無法保證全網最多或最準確的翻譯。不同分行或時間差太大的譯文不會強行拼接。純漢字日文仍無法可靠辨識。

每輪最多檢查 6 個來源、每個來源 2 或 4 個候選，最多 40 秒；插件每分鐘最多 60 次讀取，仍受 Folia 的配額限制。沒有更好的結果便保留原字幕。
