# OpenCC 繁體字幕 1.1.5

新增可捲動、可選取文字的完整診斷報告，以及查看、複製與 JSON 下載命令。逐筆記錄來源、查詢、候選比對、耗時、中文行數、對齊與拒絕原因；限流區分插件額度與 Folia 來源回覆。

報告只在記憶體保存，最多 8 首歌曲、每輪 600 個事件；超出明示省略數。不記錄帳號、憑證、原始回應或整份歌詞，不新增模組權限，查看／匯出不啟動搜尋。公開介面未提供的 HTTP 或底層堆疊無法還原。

Folia 0.7.22、0.7.23 各通過 211 項邏輯／DOM 測試，各通過 14 項 1.1.4 → 1.1.5 實際 ZIP 覆蓋與 ESM 載入檢查。使用合成來源回覆；DOM 不等於 Chromium 畫面驗證。本輪瀏覽器因缺少可用執行檔而未完成，亦未驗證 Windows 真實歌曲實播。

更新後確認顯示 1.1.5，重新搜尋出問題的歌曲，待本輪結束後匯出報告。這是診斷功能更新，尚未確認實際歌曲的字幕問題已排除。

下載專用 **opencc-traditional-lyrics-1.1.5.zip** 拖入模組面板覆蓋，重新啟用並完全退出後重開。原始碼更新包與安裝包不同。模組 ID、權限與 OpenCC 顯示字典不變；新版未簽章，須重新送審。

Folia 介面若只回傳 rate-limited，無法再確定是宿主配額還是平台限制；報告會標示不確定，不能據此認定某平台限流。
