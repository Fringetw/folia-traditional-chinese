# OpenCC 繁體字幕 1.1.4

- 修正 Acoustic ver. 等版本標記使雙語歌名無法拆解的漏配；所有別名仍保留版本資訊。
- 整首原詞完全相同、順序一致且有足夠不同片段時，可借其他錄音版本的中文，保留目前播放版本的原詞、逐字時間與動畫。
- 修正全零逐字／音節時間被誤當有效資料；行尾缺失時只依下一句已知時間或歌曲長度恢復基本顯示。
- 切歌時優先使用目前歌曲 metadata，避免前一首音訊長度擋掉正確字幕。
- 設定標題顯示 v1.1.4，字幕診斷補上「歌詞樣式 → 字幕 → 翻譯／兩者」提示。

Folia 0.7.22、0.7.23 各通過 182 項測試；Chromium 實際宿主瀏覽器回歸 38／38 通過。使用合成的來源回覆，不代表已確認截圖中歌曲在網易雲的實際翻譯可用性，也未完成 Windows 真實歌曲實播。[驗證範圍與原始結果](../validation-1.1.4.md)。

下載專用 **opencc-traditional-lyrics-1.1.4.zip** 拖入 Folia 模組面板覆蓋安裝，完全退出並重新啟動 Folia。GitHub 原始碼更新包供開發使用。

模組 ID、權限及顯示用 OpenCC 字典不變。附件未簽章，新版必須重新送審，不能複製其他版本簽章。
