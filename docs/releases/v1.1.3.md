# OpenCC 繁體字幕 1.1.3

- 修正日本新字體、跨平台藝名與翻唱附加資訊造成的中文字幕漏配。
- 可用原字幕只補中文，保留正常原詞時間、分行、和聲與注音，處理譯句跨多個片段。
- 行時間有效、逐字資料缺失或無效時，退回逐行時間恢復基本文字與動畫。
- 保留宿主分詞更新後的中文，增加版本、來源、失敗與資料修復診斷。

Folia 0.7.22、0.7.23 各通過 168 項測試；Chromium 實際渲染回歸 26／26 通過。來源回覆為合成資料，未使用私人帳號，尚未完成使用者 Windows 的真實歌曲實播。完整範圍及舊版對照見 [驗證紀錄](../validation-1.1.3.md)。

下載 **opencc-traditional-lyrics-1.1.3.zip**，拖入 Folia 模組面板覆蓋安裝後重新啟動。原始碼更新包及 GitHub Source code ZIP 供開發使用。

附件未含 Folium 官方簽章，新版需重新送審。模組 ID 與權限不變；新增的固定 OpenCC 日本新字體資料僅供比對／搜尋，不改寫畫面日文。
