1.1.2 修正 YouTube Music 歌曲明明能在其他來源找到中文翻譯，卻因名稱比對或分行限制而沒有採用的問題。

## 修正

- 支援明確的雙語歌名副標題，例如「シャケナベイベー - Shake Na Baby」對上「シャケナベイベー」、「あぶく - Bubble」對上「あぶく」。
- 支援假名與 Hepburn 羅馬字藝名拼法，例如「Yorushika」與「ヨルシカ」；不猜測漢字藝名的讀音。
- 查不到時，依序嘗試原文歌名與歌手、只查原文歌名、完整標題與歌手。仍保留版本、候選、逾時與請求上限。
- 可合併最多 3 個來源分行補中文。不同來源有固定時間差時，須經多段不同原文核對才對齊。
- 原字幕雖可用但缺中文、又無法完整補字時，允許在原文內容與時間軸皆通過核對後，改用中文更完整的整份字幕。
- 排除間奏佔位行，避免中文覆蓋率被稀釋；來源資訊會顯示整份替換及時間差。

音樂來源維持不變，可以繼續由 YouTube Music 播放，中文字幕來自網易雲等來源。模組 ID、權限及 OpenCC 引擎與字典不變。

## 更新與確認

1. 下載 `opencc-traditional-lyrics-1.1.2.zip`，拖入 Folia「設定 → 模組」覆蓋安裝。
2. 確認模組面板顯示 1.1.2 並已啟用，模組設定的「自動尋找中文字幕」已開啟。
3. 播放歌曲，執行命令「重新尋找中文字幕」，再用「查看字幕來源與中文覆蓋率」確認結果。
4. 若覆蓋率大於 0 但畫面仍沒有中文，請確認歌詞樣式的「字幕」內容包含翻譯。原有音樂／來源標籤不一定反映模組的顯示改寫。

修正版仍是未簽章的 GitHub 安裝包；市場需重新審查及簽章，以 [模組市場](https://folium-compound.cielaniska.top/#mod-opencc-traditional-lyrics) 版本為準。
