1.0.1 是文件與發布流程的維護更新，歌詞轉換功能維持原有行為。

## 變更

- 安裝說明優先導向 Folium 模組市場，區分市場簽章版本與 GitHub 未簽章建置。
- 安裝 ZIP 統一命名為 `opencc-traditional-lyrics-1.0.1.zip`，並包含預覽圖與完整第三方授權。
- 開發驗證報告移至原始碼倉庫的 `docs/`，不再放進使用者安裝包。
- 新增可在本儲存庫直接執行的檢查、測試與打包指令。
- 新增 GitHub Actions：分別對 Folia v0.7.22、v0.7.23 測試，成功後產生安裝 ZIP 與 SHA-256 校驗檔。

## 安裝與簽章

附件 `opencc-traditional-lyrics-1.0.1.zip` 為 GitHub 建置的未簽章安裝包。市場中的簽章版本需通過 Folium 的新版審查，請以 [模組市場](https://folium-compound.cielaniska.top/#mod-opencc-traditional-lyrics) 顯示的版本為準。

手動安裝時，將專用 ZIP 拖入 Folia「設定 → 模組」並啟用。GitHub 自動產生的 Source code 壓縮包供開發使用。

## 驗證與限制

已在 Folia v0.7.22、v0.7.23 各通過 41 項自動測試，包含實際建置 ZIP 的安裝與覆蓋安裝；沒有完整 Electron GUI 播放驗證。

純漢字日文無法可靠辨識，仍建議日文歌只開啟中文譯文轉換。字典與引擎維持 opencc-js 1.4.2。
