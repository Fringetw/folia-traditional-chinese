首次發布：使用 OpenCC 將 Folia 的簡體歌詞與中文譯文轉成繁體，保留逐字時間軸。

## 安裝

建議使用 [Folium 模組市場的簽章版本](https://folium-compound.cielaniska.top/#mod-opencc-traditional-lyrics)。1.0.0 已通過維護者的安全與功能審查並收錄。

若要手動安裝，下載附件 [traditional-lyrics-1.0.0.zip](https://github.com/Fringetw/folia-traditional-chinese/releases/download/v1.0.0/traditional-lyrics-1.0.0.zip)，拖入 Folia「設定 → 模組」並啟用。此 GitHub 附件為未簽章的手動安裝包，與市場簽章版本分開提供。

## 功能

- 支援原文歌詞、和聲與中文譯文，可分別開關。
- 可選臺灣繁體或 OpenCC 標準繁體。
- 字典隨插件附上，可完全離線使用。
- 設定變更立即套用，停用時還原原始顯示資料。
- 不覆寫原始歌詞檔。

## 相容性與限制

最低 Folia 版本為 0.7.22。初版通過 41 項自動測試；自動測試不等於完整 Electron 介面的播放驗證。

本插件不提供跨語言翻譯。日文歌建議只啟用中文譯文轉換，避免純漢字日文被轉換。
