- 在實際公開 Omni 服務上驗證查詢參數、候選 ref 與 AbortSignal；僅替換來源回覆，沒有連線私人帳號。

## 明確限制

平台搜尋與字幕回覆使用可重現的測試資料；未使用使用者的帳號或登入憑證，未驗證各個平台目前的網路可用性，也沒有完整 Electron GUI 播放實測。新增的 GitHub Actions 尚須上傳後在 GitHub 實際執行。

這些測試驗證的是匹配、資料處理與備援行為，不等於語言翻譯正確性。沒有 AI 語意評審，純漢字日文仍可能被誤判為中文。可用候選受來源設定、帳號、搜尋首頁、數量與逾時限制影響。

## 版本與授權

原有 `converter.mjs`、`vendor/opencc-cn2t-1.4.2.mjs` 未更動；沒有新增執行依賴或模組權限。模組只有客戶端入口，未加入原始平台端點、自己的伺服器或憑證讀取。

安裝包未包含官方簽章，需按本版原始碼重新送審。
