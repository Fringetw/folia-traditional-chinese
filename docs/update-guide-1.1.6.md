# 更新至 1.1.6

本版修正 Folia 0.7.25 報告中的 Acoustic 雙語歌名重複標記，以及可精確核對的日文姓名前後順序。

1. 將本次附件 `opencc-traditional-lyrics-1.1.6.zip` 拖入 Folia「設定 → 模組」，覆蓋安裝。
2. 重新啟用並完成 Folia 的確認。新版未簽章。
3. 從系統匣完整退出 Folia，再開啟；只關閉視窗可能仍在背景執行舊版。
4. 確認模組管理、設定標題與診斷均顯示 **1.1.6**。
5. 播放同一首問題歌曲，執行一次「重新尋找中文字幕」，等待本輪結束。

「查看字幕來源與中文覆蓋率」若仍為 0%，複製或下載完整診斷報告。若覆蓋率已大於 0 而未顯示中文，Folia 0.7.25 的底部字幕排列需包含「翻譯」；這與副字幕內容可能是不同設定。

`folia-traditional-chinese-1.1.6-update.zip` 是原始碼與測試報告，不是 Folia 安裝包。GitHub 尚未被本次任務改寫；要更新儲存庫時使用此原始碼包。不要沿用其他版本的簽章。
