# 安裝與更新 1.1.4

## Folia 安裝

1. 將 **opencc-traditional-lyrics-1.1.4.zip** 拖入「設定 → 模組」，覆蓋同一個 opencc-traditional-lyrics；不用解壓縮。
2. 完全退出 Folia，再重新啟動。開啟模組設定，標題必須顯示 **OpenCC 繁體字幕 v1.1.4**；只有 ZIP 檔名不同，不代表目前執行的程式已更新。
3. 維持「自動尋找中文字幕」與「字幕載入失敗時自動改用其他來源」開啟。你截圖中的全域歌詞來源與這兩個模組選項已開啟，不必清空資料庫或重新登入。
4. 在歌詞樣式的「字幕」選擇 **翻譯** 或 **兩者**。這與「歌詞匹配優先順序」不同；選擇不顯示翻譯時，即使中文已補入仍會看到日文。
5. 播放後用命令面板執行「查看字幕來源與中文覆蓋率」，訊息以 **OpenCC v1.1.4** 開頭。需要時執行一次「重新尋找中文字幕」。

Folia 原有「歌詞：YT Music」標籤可能仍顯示宿主原來源，不能只靠它判斷中文是否補入。模組不切換音樂來源，也不改寫你的字幕樣式選擇。

Acoustic 版本只有在完整原詞序列被證明相同時，才會借用其他錄音的中文；原字幕全無且歌手別名無法確認時，仍須在 Folia 原有線上匹配視窗選對版本並按儲存。若來源真的沒有歌詞或全部請求都失敗，插件無法憑空產生翻譯與精確逐字時間。

狀態中的逾時、需要登入、來源限制與請求上限是實際來源存取結果，不代表歌曲一定沒有字幕。回報時提供版本／來源訊息及相關 [OpenCC] 日誌即可，不需要憑證或全部帳號日誌。

## GitHub 更新與送審

**folia-traditional-chinese-1.1.4-update.zip** 是原始碼與測試報告，不能當 Folia 安裝包。解壓縮後，將 folia-traditional-chinese/ 內的內容上傳到儲存庫根目錄，保留 .github/workflows/ci.yml 與 .gitignore。此次沒有上傳或改寫 GitHub 主分支、Release。

待 GitHub Actions 成功，再以同一個 commit 建立 v1.1.4 tag 與 Release，附件使用專用安裝 ZIP。發布說明見 docs/releases/v1.1.4.md。模組 ID 保持 opencc-traditional-lyrics，送審版本為 v1.1.4 或相符 commit，渠道保持原設定，主程式授權 MIT，內附字典保留 Apache-2.0。

新版未簽章，須重新送審；不能沿用其他版本簽章。測試使用合成資料與真正宿主管線，尚未驗證使用者 Windows 的真實歌曲實播。
