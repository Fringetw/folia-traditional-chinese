## 舊版對照與測試環境排查

對照 1.1.2 時，曾遇字型 NetworkError；另一次啟動遭自動審查中止。排查確認宿主 Vite 會向 namoe.izuna.top 查詢 commit 名稱，請求只帶 commit hash。此驗證不需要該外部服務，因此已在測試專用 Node fetch、瀏覽器 HTTP／WebSocket 加上本機限制，並封鎖本機歌詞轉送代理。這些限制不會打包進插件。

也找到強制中斷後留下的兩份測試探針與字型目錄。宿主 registry 會提早載入所有探針的 CSS，導致本輪字型載入受干擾。先保存這些本次測試暫存檔，再移離 registry；啟動器現在會檢查殘留檔並明確停止，不自動覆蓋或刪除其他探針。

清理後的舊版對照完成 7 項檢查：原動畫資料保留 3 項通過，三種名稱的中文選擇與空白翻唱恢復共 4 項失敗；後續截圖在 8 秒期限內未完成而中止。原始報告的 completed 為 false，不能把未執行的其餘項目當成通過；見 [舊版部分結果](validation/browser-1.1.2-baseline.json)。同一環境、同一套測試的修復版則完成全部 26 項並通過，瀏覽器沒有失敗請求或未處理錯誤。
