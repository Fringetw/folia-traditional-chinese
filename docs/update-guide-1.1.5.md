# 安裝與回報 1.1.5

1. 將 **opencc-traditional-lyrics-1.1.5.zip** 拖入 Folia「設定 → 模組」覆蓋安裝，重新啟用。
2. 完全退出 Folia，再開啟；若關閉視窗會縮到系統匣，須從系統匣選退出。確認設定標題與狀態開頭顯示 **1.1.5**。
3. 播放出問題的歌曲，執行一次「重新尋找中文字幕」。等待搜尋結束，通常在 40 秒上限內；請不要連按重試，以免耗盡請求配額。
4. 在模組設定的「完整診斷報告」區，選「下載報告（JSON）」或「複製完整報告」。也能用命令「查看／複製／下載完整診斷報告」。
5. 若報告狀態仍是搜尋中，先等本輪結束再匯出；若已達請求上限，等至少一分鐘，來源要求更久時依來源限制處理，再手動搜尋。
6. 回傳 JSON 與出問題的畫面。報告已有版本、來源與時戳，不需要提供帳號、cookie、token 或密碼。

舊版只有彙總次數，不能回補本輪新增的逐筆紀錄。更新後需要至少重新搜尋一次。每次重新搜尋建立新報告；切換帳號、停用或重啟會清除記憶體紀錄。

報告會顯示查詢、候選歌名／歌手、耗時、中文行數、名稱與版本證據、對齊錨點、套用判定，以及失敗來自搜尋或讀取字幕。插件請求額度與 Folia 公開介面回傳的請求上限分開記錄；沒有由公開介面提供的 HTTP 狀態或底層堆疊無法還原。各原因計數可能重疊，不能相加當作歌曲數。

若自動複製遭拒，面板會展開並選取報告，可按 Ctrl+C。下載功能若不可用，會如實提示並保留文字供手動複製。查看與匯出不會額外搜尋歌曲。

本版保留先前匹配與動畫修復，主要補齊診斷工具；尚未確認目前實際歌曲的 0% 或空白字幕問題已排除。未簽章，需要重新送審。
