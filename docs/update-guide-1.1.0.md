## 更新 GitHub

1. 將原始碼更新 ZIP 解壓縮，打開內層 `folia-traditional-chinese/`。
2. 將其中的檔案與資料夾更新至儲存庫根目錄，避免多包一層同名資料夾。保留現有 Git 歷史。
3. **確認隱藏項目 `.github/workflows/ci.yml` 與 `.gitignore` 也有上傳。** 先前的 GitHub 網頁上傳沒有包含它們；本包已補回。Windows 可在檔案總管開啟「顯示隱藏的項目」，或用 Git 提交整份目錄。若網頁拖曳遺漏，使用 Add file → Create new file，依上述完整路徑建立並貼上檔案內容。
4. 在 Actions 等待 Folia v0.7.22、v0.7.23 的檢查與測試都通過。CI 工作流程只測試與打包，不自動發布或簽章。
5. 使用通過檢查的同一個 commit 建立 `v1.1.0` 標籤及 Release，標題可用 `OpenCC 繁體字幕 v1.1.0`。
6. 將 `docs/releases/v1.1.0.md` 的內容貼到 Release notes，附上對應的專用安裝 ZIP。舊版 Release 與安裝包可以保留。

## 模組市場更新

建立「模組更新 / Mod update」issue：

- 標題：`[模組更新] OpenCC 繁體字幕 v1.1.0`
- 模組 ID：`opencc-traditional-lyrics`
- 版本：`v1.1.0`（先確認標籤存在，且指向本次程式碼）
- 發布渠道：保持不變。
- 更新說明：使用下方文字，並據實補充你在 Folia 內的試用結果。

> 1.1.0 新增自動尋找中文字幕與字幕載入失敗後的備援。透過公開 Folium Omni 介面搜尋已設定來源，以歌名、歌手、版本與已知時長核對歌曲，再檢查中文覆蓋率、格式與時間軸。原字幕可用時，只補上原文相同、時間接近的缺漏中文；原字幕不可用時嘗試整份匹配備援。失敗、逾時或無效結果會跳過。新增取消、請求上限、記憶體暫存、帳號切換清理，以及重新尋找、還原與來源資訊命令。字幕搜尋會透過 Folia 將歌名與歌手查詢傳給已設定的來源，沿用 Folia 登入狀態；不讀取帳號憑證、不使用自己的伺服器、不下載執行遠端程式碼。未新增模組權限，原始碼倉庫、模組目錄及 ID 維持不變。已在 Folia v0.7.22、v0.7.23 各通過 111 項自動測試，來源回覆使用測試資料，尚未完成各平台真人帳號與完整 GUI 播放驗證。品質檢查不保證翻譯語意正確。請協助重新審查、簽章。

不要把其他版本的 `folium.sig.json` 放進新版。這次新增了線上字幕讀取功能，送審說明應如實提及。

## 建議在你自己的 Folia 試用

先安裝新版，保留你正在使用的登入與來源設定：

1. 播放原字幕缺少中文的外文歌曲，使用「查看字幕來源與中文覆蓋率」確認搜尋結果。
2. 播放原本已有完整中文的歌，確認不會無故換字。
3. 在其中一個來源無法使用時，確認可以從其他已設定來源取得候選。請求暫時失敗也可以手動「重新尋找中文字幕」。
4. 搜尋途中快速切歌，再使用「還原這首歌的原字幕」及停用模組，確認字幕與時間軸正常。

沒有符合條件的候選時保留原字幕屬於預期行為；插件不會自行產生新的外語翻譯。
