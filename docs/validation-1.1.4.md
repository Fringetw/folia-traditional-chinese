# 1.1.4 修復與驗證

日期：2026-10-31。依本次五張截圖檢查 Acoustic 雙語歌名、來源選擇及空白動畫。最後兩張顯示全域歌詞與模組搜尋選項已開啟；未顯示歌詞樣式的字幕內容選擇，不能據此斷定畫面已啟用翻譯。

保留 1.1.3 原始碼的 56 個檔案，保存差異、完整來源及 SHA-256，於獨立 fix/lyrics-1.1.4 工作目錄修正。原三份舊工作目錄及 1.1.3 修復目錄沒有被覆蓋。本次唯讀檢查 GitHub main 的 mod.json 仍為 1.1.1，沒有更新遠端主分支或 Release。

## 找到的問題

1. 舊版遇版本標記會停止拆解雙語歌名，因此「青のすみか (Acoustic ver.) - Where Our Blue Is」產生過長查詢，且無法對上相同 Acoustic Version 的候選。現在拆解時把版本傳到所有別名，正規化同類版本標記；分部、年份等保護保留。
2. 原先逐字／音節時間 start == end 被當成有效。整組全零時，資料不會走顯示修復。現在需要有實際重疊於該行、具有正時長的有效文字；無效時退回逐行顯示。
3. 行尾缺失或等於起點時，原先直接跳過。現在只依下一個已知 cue，或最後一句的有效歌曲長度恢復；不捏造開始時間或精確逐字時間，同時起始的無時間文本不會分配虛構的節奏。
4. 切歌初期播放器可能回報前一首音訊長度，導致可用原詞被判成超出歌曲範圍。現在優先採目前歌曲 metadata，缺少時才用播放長度。
5. 不同錄音的時間節奏可能無法以固定偏移對齊。新增的補譯證據要求整首原詞正規化後完全相等、順序一致、至少 24 字，且兩邊都有至少 3 個不同片段；只補中文，從不以此取代空白原字幕或播放版本的時間。只要其中一句不同，跨錄音的專用候選就不套用。

瀏覽器使用真正的 Folium client API、公開 Omni 邊界、宿主事件、歌詞 setter、重新載入及 Partita／Sonnet／Diorama 渲染器。新增檢查包含 Acoustic 歌名、完整原詞補譯、保留原逐字時間、主要載入未完成時不提前覆蓋、載入完成後套用快取、全零逐字時間、缺少行尾，以及開關翻譯字幕時資料與可見文字的差別。所有 38 項都已完成，無未處理瀏覽器／React 錯誤，沒有失敗的瀏覽器請求。最後重測將主要文字的檢查限制於 Partita 主歌詞容器、畫面範圍與預期當前字詞，避免背景字或前一句殘影混入。

初次瀏覽器執行因環境遺失 Chromium 而啟動失敗，0 項檢查不算通過；重新安裝後取得首輪 38／38。補強主歌詞可見性後曾遇 8 秒截圖逾時；測試改為預載全部合成中文需要的字形，將截圖操作期限改為 15 秒，保留 180 秒總上限與原有斷言，再完成最終 38／38。這些只調整驗證環境，沒有放寬歌曲匹配或改動插件來繞過失敗。測試仍只允許本機 HTTP／WebSocket，Vite 的外部 fetch 也會阻擋，使用全新 context，不讀私人帳號。整輪預設 180 秒上限，個別操作也有逾時，報告逐項保存。

舊版 1.1.3 的額外瀏覽器對照為 30／38；見 [原始記錄](validation/browser-1.1.3-vs-1.1.4.json)。該輪對照採較短的翻譯等待期限，可用來觀察重現條件，但不能把每個單項逾時都當成獨立程式缺陷；因果證據以修改前已失敗、修改後通過的 14 項邏輯回歸為準。

## 範圍限制

來源回覆使用自行撰寫的合成日文／中文句子，沒有複製真實歌曲歌詞。歌名與藝名的形狀取自回報條件，但這不能證明截圖歌曲的 Acoustic 版在網易雲必定提供中文，也不代表已驗證帳號、地區、網路或每首歌的翻譯語意品質。尚未在使用者 Windows Folia 中進行真實歌曲實播。

全零資料可恢復基本逐行顯示，無法重建來源未提供的精確逐字節奏。若全無歌詞、來源拒絕存取、整首原詞不一致或缺少足夠身分證據，保留原詞／空白狀態並回報原因，不能冒用其他歌曲。
