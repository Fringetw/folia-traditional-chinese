# 1.1.2 驗證紀錄

基於 GitHub 原始碼 `749cbfc781702f3e85fe6beadd5609c3b023eacf`；模組 ID 保持 `opencc-traditional-lyrics`。

## 已重現的原因

1. 1.1.1 對「シャケナベイベー - Shake Na Baby／AKASAKI」與「シャケナベイベー／AKASAKI」給出匹配分數 0，候選在讀取字幕前就被排除。
2. 「あぶく - Bubble／Yorushika」與「あぶく／ヨルシカ」同樣得到 0。雙語標題與假名／羅馬字藝名都未處理。
3. 原字幕只要可用，舊流程只補完全相同、時間相差不超過 2 秒的行，不會因另一份中文較完整而切換整份。
4. 宿主真正的 LRC 解析器會加入間奏「......」，舊覆蓋率計算把它算成沒有翻譯的歌詞行。

## 修正與限制

- 使用明確跨文字的標題副名及假名／Hepburn 拼法。保留分部、重製年份、現場／翻唱等限制；也避免把影片標題的歌手前綴誤當歌名。
- 每個來源最多 3 種查詢，候選讀取總數維持標準 2 個／深入 4 個，每次最多 6 個來源、2 個工作、40 秒及每分鐘 60 次讀取。
- 支援最多 3 個相鄰來源分行的譯文合併。固定時間差須有至少 3 個不同且有順序的原文錨點，合計至少 24 字；匹配覆蓋至少 70%，時間差不超過 12 秒且各錨點誤差不超過 2 秒。
- 已有原字幕的整份替換，還需內容對應覆蓋至少 85%，且中文覆蓋／品質分數實質提升。替換時對齊行、逐字、音節、注音與和聲的時間，不修改原始字幕檔或音樂來源。
- YT 影片時長差超出一般門檻但不超過 18 秒時，只能作為需進一步核對內容的候選，不能單憑名稱用作空字幕備援。
