# Folia OpenCC 繁體字幕

為 [Folia](https://github.com/chthollyphile/folia-major) 提供簡轉繁、尋找中文字幕與載入失敗後的字幕備援。模組 ID 保持 `opencc-traditional-lyrics`，可以覆蓋舊版更新。

本分支為 **1.1.6**，修正雙語歌名兩側皆有 Acoustic 等相同版本標記時重複附加、導致正確候選漏配的問題；也支援以精確假名讀音核對兩個拉丁姓名詞的前後順序。沿用完整診斷、逐字時間保留與空白字幕備援。本版針對使用者 Folia 0.7.25 報告重現並修復名稱漏配；真實平台字幕內容與 Windows 實播仍須另外確認。此儲存庫的安裝包未簽章。

## 安裝

建議從 [Folium 模組市場](https://folium-compound.cielaniska.top/#mod-opencc-traditional-lyrics) 安裝經審查、簽章的版本。

手動安裝 1.1.6：

1. 取得本次交付的 `opencc-traditional-lyrics-1.1.6.zip`，或版本發布後至 [Releases](https://github.com/Fringetw/folia-traditional-chinese/releases) 下載。
2. 開啟 Folia 桌面版「設定 → 模組」，啟用模組系統。
3. 將 ZIP 拖入模組面板，覆蓋安裝後啟用「OpenCC 繁體字幕」，再重新啟動 Folia。不必解壓縮。
4. 到模組設定調整簡轉繁與字幕搜尋選項。

GitHub 自動產生的 Source code 壓縮包供開發使用。舊版 1.0.0 的手動安裝附件名稱為 `traditional-lyrics-1.0.0.zip`；1.0.1 起使用 `opencc-traditional-lyrics-<版本>.zip`。

本儲存庫自行打包的 ZIP 未包含 Folium 官方簽章。市場的既有簽章不能複製到修改後的版本，新版須重新送審。

## 自動尋找中文字幕

預設開啟「自動尋找中文字幕」和「字幕載入失敗時自動改用其他來源」。

- 只透過 Folia 的公開 Omni 介面讀取已設定、支援搜尋與歌詞的來源；實際能使用哪些平台，取決於 Folia 的環境與登入狀態。
- 核對歌名、歌手、版本與已知時長。支援明確的跨文字歌名副標題，例如「あぶく - Bubble」對上「あぶく」，以及假名與 Hepburn 羅馬字藝名拼法，例如「Yorushika」對上「ヨルシカ」；不猜測漢字藝名的讀音。分部、年份與現場／混音等版本資訊仍保留。
- 比較中文譯文覆蓋的歌詞行數，排除亂碼、佔位文字、署名與明顯異常的重複譯文。不是以中文字數越多越好。
- 原字幕可用時優先保留原文、逐字時間軸、和聲與注音，從原文能對上的候選補齊中文；最多可合併來源的 3 個相鄰分行。多段不同原文能證明固定時間差時，先對齊再補字。已有正常譯文的行優先保留。
- 可用原字幕只補中文，保留正常逐字時間與原文分行；支援一個完整譯句對應多個片段。原字幕為空或行時間無效時，仍須精確歌名、歌手及有效播放時間範圍，才能採用整份備援。
- 新增日本新字體比對／搜尋（怪獸／怪獣）及翻唱呈現資訊解析。藝名無法直接對應時，只有足夠原詞與時間證據才能借用譯文，不能靠猜測替換空字幕。
- 逐字資料缺失、全零或無效時，退回有效行時間恢復基本顯示；行尾缺失時，只使用下一句已知時間或最後一句的歌曲長度，不產生未知的精確逐字時間。
- 搜尋或字幕請求失敗、逾時、無字幕、時間軸錯誤時，自動嘗試其他候選。沒有更好的結果便保留原字幕，不無限重試。
- 原字幕已有完整且格式正常的中文時，省略自動搜尋；仍可使用命令手動重新尋找。

這是**完整度與格式檢查**，不是 AI 語意評審，也不會自行翻譯外文。無法保證找出全網最多、最準確的翻譯；流暢但譯意錯誤的字幕也可能通過檢查。無法核對的分行、版本或不穩定的時間差不會強行套用。固定時間差須有至少 3 個不同原文錨點、24 字及足夠內容覆蓋支持；最多調整 12 秒，錨點誤差不得超過 2 秒。藝名身分未確認時，原詞與時間對應覆蓋須至少 85%。另一條補譯路徑要求整首原詞正規化後完全相等、順序一致、至少 24 字與 3 個不同的原詞片段；可用於 Acoustic／Live／Cover 的不同錄音，但只借中文，不替換原詞或時間。分部、年份、混音等其他標記不能因此刪除。YT Music 的影片時長相差超過一般門檻但不超過 18 秒時，只允許進入內容驗證，不可單憑名稱用作空字幕備援。

### 設定與命令

「字幕搜尋範圍」可選標準（每個來源最多 2 個候選）或深入（最多 4 個）。每次最多檢查 6 個已設定來源，每次查詢讀首頁最多 8 首，最多試 3 種查詢：歌名＋歌手、日本新字體歌名、只查歌名；沒有字形變體時，再以完整標題＋歌手補足。不做無限翻頁。並行工作最多 2 個，每個請求等待 7 秒，整輪最多 40 秒；插件每分鐘最多 60 次讀取，另受 Folia 配額限制。

命令面板提供：

- **切換繁體字幕**：只控制簡轉繁。
- **重新尋找中文字幕**：重新搜尋目前歌曲；請求上限仍然有效。
- **還原這首歌的原字幕**：撤銷自動補字／備援，暫停該歌曲的自動選字幕，直到手動重新尋找或該首暫存被清除。簡轉繁仍依設定生效。
- **查看完整診斷報告**：完整結果顯示在命令卡片；模組設定另有可捲動、可選取文字的「完整診斷報告」區。
- **複製完整診斷報告／下載完整診斷報告**：只匯出目前歌曲的紀錄，不會因查看或匯出而發送網路請求。
- **查看字幕來源與中文覆蓋率**：顯示補字來源、中文覆蓋率與具體原因，包括逾時、需要登入、地區／會員限制、請求上限、沒有匹配歌曲或沒有字幕。

關閉「自動尋找中文字幕」後，仍可保留「字幕載入失敗時自動改用其他來源」。兩者都關閉便只保留離線簡轉繁。停用整個模組會還原宿主原本的字幕。

模組只處理畫面字幕，不切換音樂來源：音樂可以繼續由 YouTube Music 播放，中文字幕來自網易雲或其他來源。Folia 原有來源標籤未必反映模組的顯示替換，請用「查看字幕來源與中文覆蓋率」確認。若覆蓋率大於 0 但畫面仍沒有中文，請確認歌詞樣式的「字幕」設定包含翻譯。

完整報告包含啟動／結束時間、版本、必要設定、來源、逐筆查詢、候選身分證據、中文行數、對齊錨點及拒絕原因。請求上限會區分插件自身額度與 Folia 來源回覆。公開介面沒有提供的 HTTP 狀態、回應或堆疊無法還原。舊版摘要不能回補成完整紀錄；更新後重新搜尋一次再匯出。

報告只在記憶體保存，隨歌曲暫存、帳號切換或停用而清除；不保存憑證、帳號、原始回應或整份歌詞。每輪上限 600 個事件，超出會明示省略數；每次重新搜尋會建立新報告，各原因計數可能重疊，不能相加當成歌曲數。只有按下載才輸出檔案。

搜尋結果只放在這次執行的記憶體裡，最多保留 8 首，每首完成後 10 分鐘內避免重複搜尋；再次載入、重新整理或重新搜尋時會按規則重新檢查。切換帳號會清除暫存，切歌或停用會取消等待並捨棄舊結果。

## 簡轉繁

- 內附固定版本的 OpenCC 字典，轉換不需要網路或 API 金鑰。
- 原文歌詞與和聲、中文譯文可以分別開關。
- 可選臺灣字形或 OpenCC 標準繁體；先整句轉換，再對回逐字、音節和分詞邊界。
- 不覆寫原始歌詞檔；停用後還原顯示。

日文歌若只需要中文字幕簡轉繁，可關閉「轉換原文歌詞與和聲」，保留「轉換中文譯文」。含假名或韓文的整行文字預設不轉換；純漢字日文無法可靠自動辨識，也可能影響中文字幕辨識。

不做會改變字數的地區詞彙替換，例如「软件」會轉為「軟件」，不改寫為「軟體」。與其他改寫歌詞的模組並用時，結果可能受處理順序影響。

## 網路與相容性

**自動搜尋需要網路**：會把目前的歌名與歌手作為查詢交由 Folia 已設定的音樂來源處理，沿用 Folia 的登入狀態。插件不讀取、保存或傳送帳號憑證，不使用自己的伺服器，也不下載執行遠端程式碼。沒有新增模組權限。

支援範圍為 Folia `>=0.7.22 <0.8.0`。自動搜尋需要公開的 Folium 1.7 Omni 介面；若介面不存在，仍保留簡轉繁。

已對 **Folia v0.7.22、v0.7.23** 各執行 **211 項自動測試**，包含真正的宿主 DTO、重建流程、公開 Omni 服務邊界與 ZIP 安裝器。來源回覆及失敗情境使用測試資料；沒有使用私人帳號連線測試各平台，也未完成完整 Electron GUI 播放驗證。

詳見 [1.1.6 驗證紀錄](docs/validation-1.1.6.md)、[開發方式](DEVELOPMENT.md)、[更新步驟](docs/update-guide-1.1.6.md) 與 [版本紀錄](CHANGELOG.md)。
